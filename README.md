# H2-X 砸车关

一个 90 年代街机格斗风的砸车奖励关。主角是宇树 H2-X 人形机器人，在夜间废车场里限时把一台车砸烂。

**在线试玩：** https://huanglizhuo.github.io/h2x-car-smash/

## 操作

| 键盘 | 动作 |
|---|---|
| Enter | 开始 / 重来 |
| A D（或 ← →） | 移动 |
| W（或 ↑） | 跳 |
| S（或 ↓） | 蹲 |
| U I O | 轻 / 中 / 重拳 |
| J K L | 轻 / 中 / 重脚 |
| → + 拳 | 下压肘击 |
| → + 脚 | 膝撞 |
| 空中 ↓ + 拳 / 脚 | 坠肘 / 踩踏 |
| ↓↘→ + 拳 | 崩拳 |
| ↓↙← + 脚 | 旋风腿 |
| →↓↘ + 脚 | 铁花空翻 |
| M | 静音 |

手机上碰一下屏幕，就会出现虚拟摇杆和按键；三个必杀技有一键快捷键。

车分车头、车厢、车尾三段，各有三级损坏。可以跳上后备箱和车顶，从上面往下砸。45 秒内全部砸烂就是 PERFECT。

## 技术

整个游戏只有一个 `index.html`，没有依赖，也没有构建步骤。本地运行直接用浏览器打开它就行。

- 角色、车和场景都是在浏览器里用代码画的像素图：SDF 形状 → 调色板量化 → 自动描边。
- 音效用 WebAudio 实时合成。
- 打开 `index.html#test` 会在控制台跑一组自检。
